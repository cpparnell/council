# BTC LLM Council — Backtesting Specification (v1s)

## Overview

Backtesting replaces the 60-day paper trading wait with a historical simulation. The system runs the real LLM council against historical BTC price data and pre-fetched sentiment snapshots, produces a signal DataFrame, and feeds it into `backtesting.py` for portfolio simulation. The result is the same set of performance metrics defined in v0_spec (Sharpe, drawdown, expectancy, consistency) plus trade-level attribution.

**Design principles (from v0_spec):**
- Walk-forward only — never allow future data to influence a past decision
- All indicator calculations use only data available at the simulated decision time
- Lookahead bias is prevented at the data-slicing layer, not assumed

---

## Framework

| Component | Tool |
|---|---|
| Portfolio simulation | `backtesting.py` |
| Historical price data | CCXT / Binance (same exchange already used) |
| Historical sentiment | Alternative.me Fear & Greed API (`?limit=1000`) |
| News data | Neutral stub (CryptoPanic has no historical API) |
| On-chain data | Neutral stub (same as live mode) |
| LLM agents | Real Anthropic API calls (temperature=0) |

**Cost:** ~$10–15 in API calls for one year of daily cycles (~365 × ~$0.03).

## Architecture

```
fetch_full_ohlcv()          fetch_historical_sentiment()
        │                               │
        └───────────────┬───────────────┘
                        ▼
              generate_signals()   ← async LLM loop, one cycle per date
                  │
                  │  For each date:
                  │    slice_ohlcv(full_df, as_of)      ← no lookahead
                  │    get_sentiment_for_date(history)
                  │    assemble_context(overrides...)   ← existing function, patched
                  │    run_council(ctx)                 ← existing function, unchanged
                  │    record(signal, size_pct, sl, tp)
                  │
                  ▼
        signals DataFrame (indexed by date)
          open | high | low | close | volume |
          signal | size_pct | sl_price | tp_price | conviction | vetoed
                        │
                        ▼
        backtesting.py  LLMCouncilStrategy.next()
          ├─ BUY  → self.buy(size, sl=sl_price, tp=tp_price)
          └─ SELL → self.position.close()
                        │
                        ▼
              Backtest.run() → stats dict
          Sharpe | Return% | Max Drawdown | Win Rate |
          Avg Trade | Expectancy | # Trades | Exposure%
                        │
                        ▼
          CSV: backtest_signals_YYYYMMDD.csv
          Output: printed stats table
```

### Phase 2 — Historical data module

**Goal:** Download and serve historical price and sentiment data.

**New file:** `src/backtest/data.py`

#### Functions

```python
def fetch_full_ohlcv(
    exchange,
    start_date: datetime,
    end_date: datetime,
) -> pd.DataFrame:
    """
    Download all daily OHLCV candles from start_date to end_date via CCXT.
    Handles pagination for large date ranges (CCXT limit per request is ~1000).
    Returns DataFrame with columns open/high/low/close/volume indexed by UTC date.
    Raises ValueError if fewer than 200 candles returned (can't compute EMA-200).
    """

def slice_ohlcv(
    full_df: pd.DataFrame,
    as_of: datetime,
    lookback: int = 250,
) -> pd.DataFrame:
    """
    Return the `lookback` most recent rows with index STRICTLY BEFORE as_of.
    Enforces no-lookahead: future candles are never visible at simulated time as_of.
    Raises ValueError if fewer than 200 rows available (indicator requirement).
    """

def fetch_historical_sentiment(limit: int = 1000) -> dict[date, dict]:
    """
    GET https://api.alternative.me/fng/?limit={limit}&format=json
    Returns {date: {"fear_greed_index": int, "reddit_sentiment": str, "social_volume_vs_avg": float}}
    Maps F&G value to reddit_sentiment: <30 bearish, >60 bullish, else neutral.
    social_volume_vs_avg defaults to 1.0 (no historical social volume available).
    """

def get_sentiment_for_date(
    history: dict[date, dict],
    target: datetime,
) -> dict:
    """
    Return the snapshot at or before target date.
    Falls back to nearest earlier date if exact match missing.
    Falls back to neutral stub if history is empty or target predates all data.
    """

NEUTRAL_NEWS_STUB: list[dict]  # 15 generic items, used for all backtest cycles
```

### Phase 3 — Async signal generation loop

**Goal:** Run the LLM council for each historical date and produce a signals DataFrame.

**New file:** `src/backtest/signals.py`

#### Function

```python
async def generate_signals(
    full_ohlcv: pd.DataFrame,
    sentiment_history: dict,
    start_date: datetime,
    end_date: datetime,
    initial_capital: float = 10_000.0,
    client=None,
) -> pd.DataFrame:
    """
    For each trading day T in [start_date, end_date):

    1. Slice OHLCV: slice_ohlcv(full_ohlcv, as_of=T)
    2. Get sentiment: get_sentiment_for_date(sentiment_history, T)
    3. Build portfolio dict from in-memory cash tracker (no DB)
    4. assemble_context(
           exchange=None,
           portfolio=portfolio_dict,
           timestamp=T,
           news_override=NEUTRAL_NEWS_STUB,
           sentiment_override=sentiment,
           onchain_override=NEUTRAL_ONCHAIN_STUB,
           skip_freshness=True,
       )
    5. run_council(ctx, client=client)
    6. Record row: {date: T, open, high, low, close, volume,
                   signal, size_pct, sl_price, tp_price, conviction, vetoed}
    7. Update in-memory portfolio tracker based on signal

    Returns DataFrame indexed by date.
    Logs progress: "Cycle YYYY-MM-DD: signal=BUY conviction=high"
    On AgentError for a cycle: log warning, record HOLD, continue.
    """
```

### Phase 4 — backtesting.py strategy and CLI runner

**Goal:** Simulate portfolio execution using the signals DataFrame and produce final metrics.

**New file:** `src/backtest/engine.py`

#### Strategy

```python
from backtesting import Backtest, Strategy

class LLMCouncilStrategy(Strategy):
    """
    Reads pre-computed signals from the OHLCV+signals DataFrame.
    On each bar:
      - BUY  (and no open position): self.buy(size, sl=sl_price, tp=tp_price)
      - SELL (and open position):    self.position.close()
      - HOLD: do nothing
    """
    def init(self): pass

    def next(self):
        signal   = self.data.signal[-1]
        size_pct = self.data.size_pct[-1]
        sl_price = self.data.sl_price[-1]
        tp_price = self.data.tp_price[-1]

        if signal == "BUY" and not self.position:
            if sl_price > 0 and size_pct > 0:
                self.buy(
                    size=size_pct / 100,
                    sl=sl_price,
                    tp=tp_price if tp_price > 0 else None,
                )
        elif signal == "SELL" and self.position:
            self.position.close()
```

#### Runner

```python
async def run_backtest(
    start_date: datetime,
    end_date: datetime,
    initial_capital: float = 10_000.0,
    client=None,
    save_signals_csv: bool = True,
) -> dict:
    """
    1. get_exchange(sandbox=False)  — mainnet for historical OHLCV only (no orders)
    2. fetch_full_ohlcv(exchange, start_date, end_date)
    3. fetch_historical_sentiment()
    4. generate_signals(full_ohlcv, sentiment_history, start_date, end_date, ...)
    5. bt = Backtest(signals_df, LLMCouncilStrategy, cash=initial_capital, commission=0.001)
    6. stats = bt.run()
    7. Optionally save signals_df to backtest_signals_{date}.csv
    8. Return formatted stats dict
    """
```

## Constraints

- **No lookahead bias**: `slice_ohlcv` is the single enforcement point — all data passed to agents is from rows strictly before `as_of`.
- **Walk-forward only**: The backtest runs forward in time once; no fitting on the test window.
- **Agent prompts are frozen during backtest**: Do not tune prompts based on backtest results to avoid overfitting.
- **News stub is declared, not hidden**: Logged at startup so the operator knows narrative reasoning is absent.
- **Commission**: `commission=0.001` (0.1% per side) approximates Binance spot fees.
